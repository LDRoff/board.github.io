# repitorium — статическая часть

Здесь лежит всё, что раздаётся браузеру: `index.html`, модули `js/`, стили `css/` и иконки `icons_bord/`.
Сборки нет — файлы отдаются как есть.

Запуск из корня репозитория:

```bash
node server.js
```

Затем откройте `http://<IP-адрес>:3000` (адрес печатает сам сервер).
Подробности, структура и ограничения — в `README.md` в корне проекта.
